# Design System

The visual language of PSD-gaming: tokens, components, boards, and accessibility.

## Tokens

All design values live in `src/styles/tokens.css` as CSS custom properties. Dark is the default; `[data-theme='light']` swaps them.

## Contrast

Text pairs meet 4.5:1. Controls meet 3:1. Both themes are first-class.

## Arcade Look

Deep indigo surfaces, light-lavender ink, yellow primary (violet in light), neon accents for categories and boards.
